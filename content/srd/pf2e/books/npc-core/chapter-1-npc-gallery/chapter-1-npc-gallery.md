# Chapter 1: NPC Gallery

<sup>NPC p. 7</sup>

In this chapter, you'll find all kinds of NPCs across a variety of categories and roles. Each section includes stat blocks that fit a theme, sidebars with extra details, and a section of tidbits a GM can drop into a game using these NPCs. If you need to find an NPC by level, use the [search feature](https://2e.aonprd.com/Search.aspx?q=type%3Acreature+source%3A) and filter by the level range you need.

Because [humans](https://2e.aonprd.com/Ancestries.aspx?ID=6) make up the majority of the population in most areas of Golarion, the stat blocks in this chapter are all humans. If you want to change the ancestry of a stat block, use the ancestry adjustments found [here](https://2e.aonprd.com/MonsterTemplates.aspx)!
