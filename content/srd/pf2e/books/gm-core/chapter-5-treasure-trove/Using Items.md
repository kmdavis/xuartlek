# Using Items

<sup>GMC p. 219</sup>

This section presents the rules for how characters use alchemical items, magic items, and other special items during play. Some items function automatically, while others need to be activated. While you need only swing a *[[srd/pf2e/compendium/equipment/runes/Flaming|flaming]] [[srd/pf2e/compendium/equipment/weapons/axe/Greataxe|greataxe]]* to scorch foes, you need to invest a *[[srd/pf2e/compendium/equipment/worn-items/Crown of Intellect|crown of intellect]]* for it to work, imbibe an [elixir of life](https://2e.aonprd.com/Equipment.aspx?ID=2887) to heal yourself, activate *[[srd/pf2e/compendium/equipment/worn-items/Clawed Bracers|clawed bracers]]* to climb up a wall, and [[srd/pf2e/compendium/rules-elements/actions/player-core#Cast a Spell|Cast a Spell]] using a magical scroll.
