# Using Items

<sup>GMC p. 219</sup>

This section presents the rules for how characters use alchemical items, magic items, and other special items during play. Some items function automatically, while others need to be activated. While you need only swing a *[[srd/pf2e/compendium/equipment/runes/flaming-greater|flaming]] [[srd/pf2e/compendium/equipment/weapons/axe/greataxe|greataxe]]* to scorch foes, you need to invest a *[[srd/pf2e/compendium/equipment/worn-items/crown-of-intellect|crown of intellect]]* for it to work, imbibe an [[srd/pf2e/compendium/equipment/alchemical-items/elixir-of-life|elixir of life]] to heal yourself, activate *[[srd/pf2e/compendium/equipment/worn-items/clawed-bracers|clawed bracers]]* to climb up a wall, and [[srd/pf2e/compendium/rules-elements/actions/player-core#Cast a Spell|Cast a Spell]] using a magical scroll.
