# Bellflower Toolbelt  *Item 6*

`Invested`  `Magical`  `Rare`

- **Price**: 220 gp
- **Usage**: worn belt
- **Bulk**: 1

Different versions of the _bellflower toolbelt_ are customized to appear to suit specific trades, so a belt used for carpentry would look different from a belt for baking.

**Activate** [>>](books/player-core/chapter-8-playing-the-game/actions#Actions "Two-Action") (concentrate, manipulate) **Effect** You place an object of up to 1 Bulk into the belt, transforming that object into a tool befitting the trade for which the belt was created. Each object remains transformed until it has been removed from the belt for 24 hours or someone uses a single Interact action to return it to its normal form. If enough transformed items are in it, the belt can be used as artisan's tools for that trade.

*Source: Treasure Vault (Remastered) p. 145*
