# Summon  *Trait*

`Summon`

Spells with the summon trait can conjure creatures, typically ones with a particular trait. Such creatures can be found in _Monster Core_ and similar books. Unless noted otherwise, the creature must be common, it gains the [[srd/pf2e/compendium/rules-elements/traits/player-core/Summoned|summoned]] trait, and it must appear in an unoccupied space in range large enough to contain it. The highest level of creature the spell can summon depends on the rank of the spell, as listed below. The spell can still summon a creature of a lower level if you so choose. These rules apply only to spells that have the summon trait; other spells that call or conjure items or beings but that don't have the trait, like _summon instrument_, work as explained in the spell.

| **Spell Rank** | **Maximum Creature Level** |
| --- | --- |
| 1st | –1 |
| 2nd | 1 |
| 3rd | 2 |
| 4th | 3 |
| 5th | 5 |
| 6th | 7 |
| 7th | 9 |
| 8th | 11 |
| 9th | 13 |
| 10th | 15 |

*Source: Player Core p. 360*
