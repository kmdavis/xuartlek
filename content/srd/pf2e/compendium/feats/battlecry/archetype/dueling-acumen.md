# Dueling Acumen  *Feat 2*

`Archetype`  `Skill`

- **Archetype**: [[srd/pf2e/compendium/character/archetypes/aldori-duelist|Aldori Duelist]]
- **Prerequisites**: [[srd/pf2e/compendium/feats/battlecry/archetype/aldori-duelist-dedication|Aldori Duelist Dedication]]

You're always ready for a new [[srd/pf2e/books/gm-core/chapter-4-subsystems/duels|duel]], and you've been trained to start and end fights quickly. When you're in a duel or can see exactly one creature, you can always roll Dueling [[srd/pf2e/compendium/rules-elements/skills/lore|Lore]] for initiative. If you do so while in a duel, you must choose from either Deception, Intimidation, or Perception when you roll for initiative; you're considered to have rolled the chosen skill for initiative for the purpose of dueling actions.

*Source: Battlecry! p. 54*
