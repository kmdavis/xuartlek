# Greater Mercy  *Feat 8*

`Champion`

- **Archetypes**: [[srd/pf2e/compendium/character/archetypes/Blessed One|Blessed One]] (Level 10)
- **Prerequisites**: [[srd/pf2e/compendium/feats/player-core-2/archetype/Mercy|Mercy]]

Your faith enhances your ability to remove conditions. Add the following options to the list of conditions you can counteract for any type of mercy you can grant. **Mercy of the Body** [[srd/pf2e/compendium/rules-elements/Conditions#Drained|drained]], [[srd/pf2e/compendium/rules-elements/Conditions#Slowed|slowed]]; if you're 16th level, add [[srd/pf2e/compendium/rules-elements/Conditions#Stunned|stunned]]; **Mercy of Grace** [[srd/pf2e/compendium/rules-elements/Conditions#Immobilized|immobilized]], [[srd/pf2e/compendium/rules-elements/Conditions#Restrained|restrained]], slowed; if you're 12th level, add [[srd/pf2e/compendium/rules-elements/Conditions#Petrified|petrified]]; if you're 16th level, add stunned; **Mercy of the Mind** [[srd/pf2e/compendium/rules-elements/Conditions#Confused|confused]], [[srd/pf2e/compendium/rules-elements/Conditions#Controlled|controlled]], slowed; if you're 16th level, add [[srd/pf2e/compendium/rules-elements/Conditions#Doomed|doomed]] and stunned.

*Source: Player Core 2 p. 97*
