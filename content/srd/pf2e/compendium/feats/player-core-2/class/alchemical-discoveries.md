# Alchemical Discoveries  *Feat 4*

`Investigator`

- **Prerequisites**: [[srd/pf2e/compendium/character/methodologies#Alchemical Sciences|alchemical sciences methodology]]

You've devoted extra time in the lab to improve your knowledge of alchemy. You learn the formulas for two [[srd/pf2e/compendium/rules-elements/traits/player-core/alchemical|alchemical items]] each time you level up instead of one; these must still be elixirs or tools. The number of versatile vials you can create each day increases by one if you're an expert in [[srd/pf2e/compendium/rules-elements/skills/crafting|Crafting]], two if you're a master, or three if you're legendary.

*Source: Player Core 2 p. 108*
