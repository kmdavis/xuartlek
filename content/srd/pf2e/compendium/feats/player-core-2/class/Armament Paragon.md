# Armament Paragon  *Feat 20*

`Champion`

- **Prerequisites**: blessed armament

Add the following property runes to the list you can choose for your blessed armament: animated, [[srd/pf2e/compendium/equipment/runes/fearsome|_greater fearsome_]], [[srd/pf2e/compendium/equipment/runes/grievous|_grievous_]], [[srd/pf2e/compendium/equipment/runes/keen|_keen_]], and [[srd/pf2e/compendium/equipment/runes/vitalizing|_greater vitalizing_]]. If you have the Radiant Armament feat, add [[srd/pf2e/compendium/equipment/runes/astral|_greater astral_]] and [[srd/pf2e/compendium/equipment/runes/brilliant|_greater brilliant_]] to the list as well. In addition, you can change the rune you've selected for the day to a different rune from your list as a single action that has the [[srd/pf2e/compendium/rules-elements/traits/player-core/concentrate|concentrate]] and [[srd/pf2e/compendium/rules-elements/traits/player-core/divine|divine]] traits. Changing the rune doesn't restore abilities that can be used only a limited number of times.

*Source: Player Core 2 p. 99*
