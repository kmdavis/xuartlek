# Furious Sprint  *Feat 10*  [?](rules/player-core/chapter-8-playing-the-game/actions#Actions "Varies")

`Barbarian`  `Rage`

You rush forward. Stride up to five times, or up to eight times if you used 3 actions. All this movement must be in a straight line (though the GM might allow reasonable variance). You can replace any of these Strides with a Balance action if you need to, which you attempt using an Athletics check instead of an Acrobatics check, using the same DC.
