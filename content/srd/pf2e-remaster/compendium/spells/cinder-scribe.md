# Cinder Scribe  *Spell 1*  [>>](rules/player-core/chapter-8-playing-the-game/actions#Actions "Two-Action")

`Fire`  `Manipulate`  `Uncommon`

- **Traditions**: Arcane, Divine, Occult, Primal
- **Range**: touch
- **Target**: one object (see below)
- **Duration**: 24 hours

Conjuring a quill of magical flame, you take an object and write a message onto it that disappears to the naked eye almost as soon as you finish writing it. If this message is written onto an object that can't withstand a burning fire, such as paper or leather, then the object is destroyed while you're writing it. If the inscribed object is thrust into a roaring fire, the writing on it is revealed for 1 minute before fading. The writing can be revealed this way any number of times, and it's erased only if it's counteracted by an effect similar to _dispel magic_ or when the duration ends. Even if the object is destroyed, pieces of the message exist on its various parts. For example, if the object was turned to dust and recreated via remake, the message would remain intact.

---
**Heightened (2nd)** The duration increases to a year and a day.

**Heightened (4th)** The duration is unlimited.
