# (concentrate)

**Activate** [ ](rules/player-core/chapter-8-playing-the-game/actions#Actions "Free Action") (concentrate) **Frequency** once per day; **Effect** You gain 1 Focus Point, which you can use only to cast a ranger warden spell. When you use this Focus Point, the _warden’s signet_ also casts a 4th-rank _oaken resilience_ spell on you. If not used by the end of your turn, this Focus Point is lost.
