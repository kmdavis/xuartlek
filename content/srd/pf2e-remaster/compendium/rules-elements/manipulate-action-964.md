# manipulate

**Activate** [>>](rules/player-core/chapter-8-playing-the-game/actions#Actions "Two-Action") manipulate **Effect** Make up to four Strikes with the _liar's gun_. Each of the four Strikes must be against a different target within a 20-foot cone. You apply and increasing your multiple attack penalty for the four Strikes only after resolving all attacks. If the weapon misfires on any of these attacks, wait to apply the misfire until you resolve all of the attacks
