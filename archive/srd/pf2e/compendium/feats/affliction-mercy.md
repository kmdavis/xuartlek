# Affliction Mercy  *Feat 12*  
[champion](archive/srd/pf2e/rules/traits/champion.md "Champion Class Trait")  

- **Prerequisites**: [Mercy](archive/srd/pf2e/compendium/feats/mercy.md)

The divine grace that flows through you grants reprieve from an affliction. When you use [Mercy](archive/srd/pf2e/compendium/feats/mercy.md), you can instead attempt to counteract a [curse](archive/srd/pf2e/rules/traits/curse.md "Curse Effect Trait"), [disease](archive/srd/pf2e/rules/traits/disease.md "Disease Effect Trait"), or [poison](archive/srd/pf2e/rules/traits/poison.md "Poison Effect Trait").

*Source: Core Rulebook p. 113*
