# Running Reload  [>](chapter-9-playing-the-game.md#Actions "Single Action") *Feat 4*  
[ranger](archive/srd/pf2e/rules/traits/ranger.md "Ranger Class Trait")  

- **Activity** Single Action

You can reload your weapon on the move. You [Stride](archive/srd/pf2e/rules/actions/stride.md), [Step](archive/srd/pf2e/rules/actions/step.md), or [Sneak](archive/srd/pf2e/rules/actions/sneak.md), then [Interact](archive/srd/pf2e/rules/actions/interact.md) to reload.

*Source: Core Rulebook p. 172*
