# Kinetic Pinnacle  *Feat 20*  
[kineticist](kineticist-roe.md "Kineticist Class Trait")  


No one can match the pace at which elements flow from you. You're permanently [quickened](archive/srd/pf2e/rules/conditions.md#Quickened). You can use your extra action only to [Channel Elements](channel-elements-roe.md), use a 1-action [Elemental Blast](elemental-blast-roe.md), or use a 1-action stance impulse.

*Source: Rage of Elements p. 23*
